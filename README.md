# 🔐 Cryptography Masterclass

An interactive web-based platform for learning cryptography concepts through practical demonstrations.

## 🚀 Live Demo

https://monikaramachandran29-crypto.github.io/cryptography-masterclass/

## ✨ Features

- Caesar Cipher – Encryption and decryption
- RSA – Public-key cryptography demonstration
- AES – Symmetric encryption concepts
- SHA-256 – Cryptographic hashing
- Diffie–Hellman – Secure key exchange concepts

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Crypto API (where implemented)

## 🎯 Project Objective

To help students understand fundamental cryptography concepts through interactive web-based demonstrations.

## ⚠️ Disclaimer

This project is intended for educational purposes. Do not use demonstrations or experimental implementations to protect real-world sensitive information.
